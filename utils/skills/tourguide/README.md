# tourguide

Understand a change or plan one part at a time. The agent explains what changed, why,
and what it affects.

Starts with an outline and pauses after each part. Say "next" to continue, or ask a
question before moving on.

In Claude Code:

```text
/u:tourguide feature/auth-refactor
```

In Codex:

```text
$tourguide feature/auth-refactor
```

See [SKILL.md](SKILL.md) for the full workflow.
