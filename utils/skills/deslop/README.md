# deslop

Rewrite comments, copy, commit messages, PRs, or tickets in plain English. Remove filler
and wording that takes effort to understand.

Changes wording while preserving behaviour and variables. Without a target, reviews
comments and user-facing strings in the branch diff.

In Claude Code:

```text
/u:deslop README.md
```

In Codex:

```text
$deslop README.md
```

See [SKILL.md](SKILL.md) for the full workflow.
