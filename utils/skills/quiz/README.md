# quiz

Check your understanding of a change with questions based on its diff and repository
conventions. The agent explains any gaps in your answers.

Asks one question at a time, usually three, and keeps a private learning record. Use
--focus or --deep to adjust the quiz.

In Claude Code:

```text
/u:quiz --focus behaviour
```

In Codex:

```text
$quiz --focus behaviour
```

See [SKILL.md](SKILL.md) for the full workflow.
