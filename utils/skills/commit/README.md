# commit

Create one Git commit from the current changes. The agent writes a message in your
repository's style and handles pre-commit hooks.

Creates a local commit without pushing or opening a PR.

In Claude Code:

```text
/u:commit focus on the billing bug fix
```

In Codex:

```text
$commit focus on the billing bug fix
```

See [SKILL.md](SKILL.md) for the full workflow.
