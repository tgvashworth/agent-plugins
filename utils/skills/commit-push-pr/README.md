# commit-push-pr

Commit the changes, push the branch, and open a PR ready for review. An existing PR is
updated instead of duplicated.

Marks an existing draft ready, then starts review-cycle with the permissions already
granted for the task.

In Claude Code:

```text
/u:commit-push-pr describe the billing bug and how the fix was tested
```

In Codex:

```text
$commit-push-pr describe the billing bug and how the fix was tested
```

See [SKILL.md](SKILL.md) for the full workflow.
