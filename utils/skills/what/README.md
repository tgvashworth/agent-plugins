# what

Ask for the previous response to be explained again in plain English. Quote a confusing
phrase or name the part you want clarified.

Uses the conversation for context and puts the main point first.

In Claude Code:

```text
/u:what the part about the migration
```

In Codex:

```text
$what the part about the migration
```
