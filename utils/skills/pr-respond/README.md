# pr-respond

Reply to PR review comments and resolve threads whose feedback has been addressed. The
agent checks the current code before responding.

Leaves disputed or deferred threads open for the reviewer and drafts replies that need
discussion.

In Claude Code:

```text
/u:pr-respond 42
```

In Codex:

```text
$pr-respond 42
```

See [SKILL.md](SKILL.md) for the full workflow.
