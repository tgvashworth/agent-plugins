# ready-for-review

Rewrite a PR's title and description to match the current branch, then mark a draft
ready for review.

Requires the work to be committed and pushed. Continues into review-cycle with the
task's existing permissions.

In Claude Code:

```text
/u:ready-for-review 42
```

In Codex:

```text
$ready-for-review 42
```

See [SKILL.md](SKILL.md) for the full workflow.
