# commit-push-draft

Commit the changes, push the branch, and open a draft PR. An existing PR is updated
without changing its draft or ready state.

Review starts when the PR is marked ready.

In Claude Code:

```text
/u:commit-push-draft the migration still needs testing
```

In Codex:

```text
$commit-push-draft the migration still needs testing
```

See [SKILL.md](SKILL.md) for the full workflow.
