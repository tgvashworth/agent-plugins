# review-agent

Review a PR and monitor new comments and CI failures. Return findings to the session
making the changes.

Reviews without editing, committing, pushing, or posting replies. Use review-cycle to
make fixes.

In Claude Code:

```text
/u:review-agent 42
```

In Codex:

```text
$review-agent 42
```

See [SKILL.md](SKILL.md) for the full workflow.
