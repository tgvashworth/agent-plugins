# context

Get up to speed on a task, ticket, branch, or plan. The agent summarises the repository
state and suggests next steps.

Inspect the task without changing files or switching branches.

In Claude Code:

```text
/u:context https://linear.app/acme/issue/ABC-728
```

In Codex:

```text
$context https://linear.app/acme/issue/ABC-728
```
