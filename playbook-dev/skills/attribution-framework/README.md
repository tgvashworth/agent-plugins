# attribution-framework

Define how to connect a change to altered behaviour and measured outcomes. Specify the
evidence needed to support a causal claim.

Records confidence in each link and distinguishes causation from correlation.

In Claude Code:

```text
/playbook-dev:attribution-framework trace how routing changes affected resolution time
```

In Codex:

```text
$attribution-framework trace how routing changes affected resolution time
```

See [SKILL.md](SKILL.md) for the full workflow.
