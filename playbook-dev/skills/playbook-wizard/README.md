# playbook-wizard

Design an analysis playbook through a guided conversation. Define the goals, stages,
reference material, quality checks, and execution instructions.

Coordinates the other playbook skills and asks questions where the design needs your
input.

In Claude Code:

```text
/playbook-dev:playbook-wizard analyse failed customer support conversations
```

In Codex:

```text
$playbook-wizard analyse failed customer support conversations
```

See [SKILL.md](SKILL.md) for the full workflow.
