# impact-estimation

Define how to estimate the effect of proposed improvements. Set confidence levels,
evidence requirements, and criteria for comparing potential impact.

Makes the basis and uncertainty of each estimate explicit.

In Claude Code:

```text
/playbook-dev:impact-estimation estimate the impact of changes to ticket routing
```

In Codex:

```text
$impact-estimation estimate the impact of changes to ticket routing
```

See [SKILL.md](SKILL.md) for the full workflow.
