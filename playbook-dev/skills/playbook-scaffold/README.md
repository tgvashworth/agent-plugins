# playbook-scaffold

Create the directories and placeholder files for a five-stage analysis playbook. Use
this when you need the initial file layout.

Creates the structure for setup, individual analysis, aggregation, synthesis, and
finalisation, plus templates and references.

In Claude Code:

```text
/playbook-dev:playbook-scaffold create the directory structure for support ticket analysis
```

In Codex:

```text
$playbook-scaffold create the directory structure for support ticket analysis
```

See [SKILL.md](SKILL.md) for the full workflow.
