# setup-stage

Design Stage 0, which checks the environment and data before analysis starts. Define the
scope, required tools, and checks that must pass.

Setup runs sequentially and requires user confirmation before Stage 1.

In Claude Code:

```text
/playbook-dev:setup-stage define setup checks for the support ticket dataset
```

In Codex:

```text
$setup-stage define setup checks for the support ticket dataset
```

See [SKILL.md](SKILL.md) for the full workflow.
