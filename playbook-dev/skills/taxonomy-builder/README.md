# taxonomy-builder

Create categories for classifying analysis results. Define each category, its tag, and
the action it suggests.

Designs categories so every record fits and categories do not overlap.

In Claude Code:

```text
/playbook-dev:taxonomy-builder define failure categories for support tickets
```

In Codex:

```text
$taxonomy-builder define failure categories for support tickets
```

See [SKILL.md](SKILL.md) for the full workflow.
