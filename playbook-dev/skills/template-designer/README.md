# template-designer

Design templates for playbook outputs. Specify headings, placeholders, required and
optional sections, and examples.

Keeps results consistent across records, analysts, and runs.

In Claude Code:

```text
/playbook-dev:template-designer create a template for an individual ticket analysis
```

In Codex:

```text
$template-designer create a template for an individual ticket analysis
```

See [SKILL.md](SKILL.md) for the full workflow.
