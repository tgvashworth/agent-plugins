# stage-document

Write a stage README or analysis document using the playbook format. State the purpose,
execution model, inputs, outputs, and completion criteria.

Keeps instructions and output templates consistent across stages.

In Claude Code:

```text
/playbook-dev:stage-document write the README for Stage 2
```

In Codex:

```text
$stage-document write the README for Stage 2
```

See [SKILL.md](SKILL.md) for the full workflow.
