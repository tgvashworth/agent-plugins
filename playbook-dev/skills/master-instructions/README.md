# master-instructions

Write instructions.md, the main entry point for running a playbook. Define stage order,
dependencies, agent counts, and operating limits.

Documents how outputs pass between stages and when execution can continue.

In Claude Code:

```text
/playbook-dev:master-instructions write instructions.md for this support ticket playbook
```

In Codex:

```text
$master-instructions write instructions.md for this support ticket playbook
```

See [SKILL.md](SKILL.md) for the full workflow.
