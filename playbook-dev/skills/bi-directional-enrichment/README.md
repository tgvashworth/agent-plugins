# bi-directional-enrichment

Design updates that carry later findings back into earlier analysis outputs. Specify
links between records and the new information to add.

Keeps individual analyses connected to findings from aggregation and synthesis.

In Claude Code:

```text
/playbook-dev:bi-directional-enrichment add Stage 3 recommendations to the related Stage 1 analyses
```

In Codex:

```text
$bi-directional-enrichment add Stage 3 recommendations to the related Stage 1 analyses
```

See [SKILL.md](SKILL.md) for the full workflow.
