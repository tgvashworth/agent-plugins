# quality-gates

Define the checks required before, during, and after each stage. State prerequisites and
criteria for deciding whether the stage is complete.

Uses concrete pass or fail conditions to control progress between stages.

In Claude Code:

```text
/playbook-dev:quality-gates define completion criteria for Stage 1
```

In Codex:

```text
$quality-gates define completion criteria for Stage 1
```

See [SKILL.md](SKILL.md) for the full workflow.
