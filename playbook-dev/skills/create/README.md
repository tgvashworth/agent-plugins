# create

Start the guided process for creating an analysis playbook. Describe the analysis domain
and the questions the playbook should answer.

Uses playbook-wizard to create the stages, references, and validation checks under
playbook/.

In Claude Code:

```text
/playbook-dev:create customer feedback analysis for support tickets
```

In Codex:

```text
$create customer feedback analysis for support tickets
```

See [SKILL.md](SKILL.md) for the full workflow.
