# architecture-doc

Document the system being analysed. Describe components, dependencies, data flow,
integration points, and relevant code locations.

Creates a reference for agents that need system context during analysis.

In Claude Code:

```text
/playbook-dev:architecture-doc document the ticket routing system for this playbook
```

In Codex:

```text
$architecture-doc document the ticket routing system for this playbook
```

See [SKILL.md](SKILL.md) for the full workflow.
