# playbook-validator

Check a playbook's directory structure, stage documents, templates, references, quality
checks, and main instructions. Report missing or inconsistent parts.

Returns a validation report without changing the playbook. Ask separately for fixes.

In Claude Code:

```text
/playbook-dev:playbook-validator check the playbook before its first run
```

In Codex:

```text
$playbook-validator check the playbook before its first run
```

See [SKILL.md](SKILL.md) for the full workflow.
