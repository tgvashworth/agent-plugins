# meta-analysis

Assess how well the playbook and analysis process worked. Record instruction problems,
configuration errors, missing data, and suggested improvements.

Groups process issues by theme so later runs can address them.

In Claude Code:

```text
/playbook-dev:meta-analysis track problems found while running this playbook
```

In Codex:

```text
$meta-analysis track problems found while running this playbook
```

See [SKILL.md](SKILL.md) for the full workflow.
