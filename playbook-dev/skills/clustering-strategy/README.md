# clustering-strategy

Define how to group analysis results across several dimensions. Choose dimensions such
as failure type, performance, or record type.

Compares groups and combinations of factors to identify patterns and priorities.

In Claude Code:

```text
/playbook-dev:clustering-strategy group tickets by failure type, channel, and severity
```

In Codex:

```text
$clustering-strategy group tickets by failure type, channel, and severity
```

See [SKILL.md](SKILL.md) for the full workflow.
