# synthesis-stage

Design Stage 3 to turn patterns into recommendations. Define analyses for improvement
opportunities, change impact, and other questions that span the dataset.

Independent types of synthesis can run in parallel.

In Claude Code:

```text
/playbook-dev:synthesis-stage identify improvements from the support ticket clusters
```

In Codex:

```text
$synthesis-stage identify improvements from the support ticket clusters
```

See [SKILL.md](SKILL.md) for the full workflow.
