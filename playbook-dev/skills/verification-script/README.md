# verification-script

Generate scripts that check playbook outputs. Check expected files, minimum content
sizes, required formats, and stage completion.

Automates output checks so missing or incomplete analyses can be identified.

In Claude Code:

```text
/playbook-dev:verification-script check that every ticket has a completed analysis file
```

In Codex:

```text
$verification-script check that every ticket has a completed analysis file
```

See [SKILL.md](SKILL.md) for the full workflow.
