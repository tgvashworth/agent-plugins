# glossary-creator

Define the terms and metrics used in an analysis. Include calculations, thresholds,
examples, and distinctions between similar terms.

Gives all stages the same definitions to use.

In Claude Code:

```text
/playbook-dev:glossary-creator define resolution time, escalation, and repeat contact
```

In Codex:

```text
$glossary-creator define resolution time, escalation, and repeat contact
```

See [SKILL.md](SKILL.md) for the full workflow.
